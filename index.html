01 / WHAT IT FINDS

        
Everything around the picture.

        
Version 0.2's strip --all only cleared EXIF. The merged v0.3 source rebuilds the file from its picture data, so XMP, IPTC, comments and anything appended after the image go too. Tap a card for details.

04 / THE CLI

        
Scriptable, batchable, JSON.

        
Writes default to <name>.cybermeta.<ext> next to the original and are atomic: written to a temporary file, then renamed.

      

      

        
cybermeta audit ~/Pictures -r --format jsonPrivacy report for every photo, with a risk level and findings by category

        
cybermeta scrub ~/Pictures/to-share -rLossless scrub of a whole tree; keeps colour profile and rotation

        
cybermeta scrub photo.jpg --keep nonePixels only: no metadata, no profile, no rotation

        
cybermeta scrub photo.jpg --dry-runShow what would be removed; write nothing

        
cybermeta strip photo.jpg --gpsLocation only: EXIF GPS plus XMP/IPTC places; everything else stays

        
cybermeta spoof photo.jpg --preset anonymous-cameraFull scrub, then "Generic Camera"

        
cybermeta spoof photo.jpg --shift -2h30mMove every timestamp

        
cybermeta show photo.jpg --summaryTyped JSON: camera, exposure, capture time, GPS with a map link

        
cybermeta xmp write -o photo.xmp --title "…" --keyword neonXMP sidecars and packets (Ghostframe stores edit recipes here)

      

      

        
1
Split
JPEG segments, PNG chunks or WebP chunks, each labelled by what it carries.

        
2
Rebuild
Picture data copied byte for byte. JFIF thumbnails cut; trailers dropped.

        
3
Re-create
Rotation and date written as a fresh EXIF block holding only those values.

        
4
Verify
nom-exif, a parser that shares no code with the writer, re-reads the output. Leftovers mean an error, not a leaky file.

One line. Checksummed.
