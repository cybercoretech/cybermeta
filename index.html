Every photo carries
more than the picture.

Camera make, model, timestamps, GPS coordinates — all riding invisibly in the file. cybermeta reads it, edits it, strips it, or spoofs it entirely. Pixels never get re-encoded.

Read, don't alter

Inspect without
touching a pixel.

cybermeta show and cybermeta export read every tag — JSON or TSV, machine-parsable for scripts and pipes. JPEG/TIFF first-class; PNG, WebP, JXL, HEIF/AVIF wherever the underlying format can carry metadata without a pixel re-encode.

The TUI shows the same data, editable in place — no separate "read mode" vs "edit mode" to context-switch between.

Strip presets

Three ways to
disappear.

Bound to g (GPS) and X (all, with confirm) in the TUI, or --gps / --all on the CLI. Writes default to <stem>.cybermeta.<ext> — --in-place is opt-in, never the default.

Exhibit Cpresets
table
preseteffect
strip-gpsRemove GPS IFD / geolocation tags
anonymous-cameraStrip device identity; generic Make/Model
clear-allKeep structural TIFF tags only
Beyond deletion

Spoof, not just
strip.

An obviously-blank metadata block is itself a signal that something was scrubbed. cybermeta spoof --preset <name> writes plausible cover data instead of a gap — spoof --list shows every preset.

Editable string tags: Make, Model, Software, Artist, Copyright, ImageDescription, date fields, lens fields, GPS refs — all reachable via set or Enter in the TUI.

Exhibit Dspoof --preset
live
$ cybermeta spoof photo.jpg --preset anonymous-camera

Make    Canon        →  Generic
Model   EOS R6       →  Digital Camera
Software Lightroom   →  (cleared)

saved: photo.cybermeta.jpg
